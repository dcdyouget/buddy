## 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 硬编码颜色判定 | 只拦「以数字构造」的颜色 | 颜色类型本身（`Rgba` 参数、`Hsla::from`）合法；拦的是绕过令牌的字面量 |
| 豁免范围 | 仅 `tokens.rs` | 生成物是颜色的唯一来源；examples 同样受约束 |
| 提交闸门 | 新增 `scripts/gate.sh`，一律 `gate && git commit` | 两次用 `;` 连接检查与提交导致失败后仍提交（S02-02、`8cadce6`） |
| CI 依赖 tag | `gen_tokens --check` 读 `v1-final:` | 推送时必须同时推送 tag `v1-final`（当前仅本地），否则 CI 上新鲜度检查失败 |
