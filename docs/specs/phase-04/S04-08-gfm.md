## 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 定制途径 | vendored 渲染器加一组可选装饰回调 | 上游在表格 / 表头 / 加粗处直接读 zed 主题色，结构固定；集中成一个 `MarkdownDecorations`，默认上游行为，升级时只需重放一处补丁 |
| 项目符号几何 | 符号列宽 20px + 上游 4px 间距 = v1 `padding-left: 24px` | 圆点位于文字左 12px、序号徽章右缘距文字 8px、任务框在 24px 处且文字右移 21px，均按 v1 CSS 换算 |
| 引用左边 | 1px 淡边 + 覆盖在左边框上的 3px 主色竖条 | GPUI 边框四边同色，无法一边主色其余淡色 |
| 引用底色 | `soft` 预先合成到 `bg_sunken` 上作渐变起点 | v1 为两层背景（渐变叠底色），GPUI 只有一层背景 |
| 删除线 | 删除线 + 前景色 70% | v1 `opacity: 0.7`；文本运行无不透明度 |
| 链接 | 主色字；点击按 v1 `normalizeHref` 规则补 `https://` 后系统打开；`#锚点` 不打开 | 与 v1 一致（v1 页内锚点在消息中无目标） |
| 流式半截链接（D19） | 不另做 | 未闭合的 `[文字](url` 在 CommonMark 中不是链接，天然不可点；不做 mend（S04-05） |
| 原始 HTML | 按文字原样显示（`parse_html=false`，S04-03） | v1 react-markdown 默认转义；样例中含 `<kbd>` / `<b>` 供目检 |
| 图片 | 实现 GPUI HTTP 客户端（reqwest），只加载 `http(s)` | 任务 D30 要求渲染 + 失败占位；不引入新包；相对路径 / `file:` 在 v1 webview 中同样不显示 |
| 已知差距 | ① 行内代码无 1px 边框、字号与正文同为 14px（v1 13px；GPUI 同一行只能一个字号）；② 链接悬停无下划线动画、表格行悬停无底色；③ 标题字距（GPUI 不支持，同 S03-05）；④ 图片为上游样式（圆角 md，v1 为直角 `max-width:100%`）；⑤ 图片请求走 `HTTP(S)_PROXY` 环境变量，v1 webview 走系统代理 | 目检时请判断是否可接受 |
