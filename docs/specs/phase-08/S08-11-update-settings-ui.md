## 目标

设置页「软件更新」区域：显示当前版本，手动检查、展示新版本与更新说明、下载进度、安装与重启，状态和文案对齐 v1 `UpdateSetting`。

## 输入

- v1 `src/components/settings/UpdateSetting.tsx` 与 `src/styles/global.css` `.update-setting*`（视觉与文案真值）
- v1 设置页顺序：外观 → 呼出快捷键 → 软件更新 → 模型

## 实现要点

| ID | 事项 | 说明 |
|----|------|------|
| — | 状态 | 未检查 / 正在检查（图标 1.2s 旋转，减弱动效时静止）/ 已是最新 / 发现新版本（版本号 + 说明 + 「立即更新」）/ 下载百分比 / 正在安装 / 等待回复结束 / 正在重启 / 失败（中文原因 + 「重新检查」） |
| — | 按钮 | 「检查更新」→「正在检查…」/「正在更新…」/「重新检查」，进行中禁用；「立即更新」为主色按钮 |
| — | 键盘 | 两个按钮加入设置页 Tab 顺序（热键之后、模型之前），Enter / Space 触发，Tab 时滚入视口 |
| — | 组件 | `crates/ui/src/settings/update.rs`（状态与动作）、`update_view.rs`（绘制）；新增 lucide `refresh-cw` 图标 |
| — | 差异 | 下载进度总量取清单 `size`，不再有 v1 的不确定进度条；安装 / 重启阶段显示满进度 |

## 备注

目检步骤（任一安装方式的 0.1.0 均可）：打开 Buddy → 设置 → 「软件更新」位于快捷键与模型之间，副标题「当前版本 v0.1.0」；
点「检查更新」应短暂显示「正在检查…」后出现绿色「当前已是最新版本」；断网再点应出现红色失败提示并可「重新检查」。
「发现新版本」卡片需线上发布更高版本后才能看到。
