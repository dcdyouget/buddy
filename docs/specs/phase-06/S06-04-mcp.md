## 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| UI 范围核查 | 按当前 v1 保留无 MCP 设置入口；本项核对配置契约、无损往返及其他设置编辑保留 MCP | SettingsPage / 设置组件与 configStore 均无 MCP 用户操作；任务素材 D12 是设想。用户要求按运行的 v1 源码迁移，因此不把配置结构误当已实现的配置界面。 |
| 运行时范围 | 不显示连接状态，不启动服务或注入工具 | engine 的 MCP 模块仍为占位，与当前 v1 一致；配置数据存在不意味着可连接。后续运行时能力须另立需求。 |
| 既有校验契约 | 保留 stdio command / SSE url 的非空校验及 serde 必填字段；不新增 trim / URL 格式 / timeout 取值限制 | 当前校验不拒绝空白字符串、空 id/name 或 timeout=0；本项记录并测试现状，不暗中改变已存配置的解释。 |
